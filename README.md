# \# Kitchen Rush

# 

# A chaotic cooperative cooking game that runs in your browser. Play together on one screen, or connect phones on the same Wi-Fi network to use them as controllers.

# 

# \## Features

# 

# \- Cooperative cooking gameplay

# \- Phone-based controllers

# \- Local multiplayer over Wi-Fi

# \- Browser-based graphics using HTML Canvas

# \- Node.js server

# 

# \## Requirements

# 

# \- Node.js 18 or later

# \- A modern web browser

# \- The same Wi-Fi network for the host computer and phone controllers

# 

# \## Run locally

# 

# 1\. Install Node.js.

# 2\. Open a terminal in the project directory.

# 3\. Start the server:

# 

# &#x20;  ```bash

# &#x20;  node server.js

# &#x20;  ```

# 

# 4\. Open the local address printed by the server in your browser.

# 5\. Connect your phone to the same Wi-Fi network and follow the controller instructions displayed by the game.

#
