# \# Kitchen Rush 

# 

# A cooperative browser cooking game. Run the game on your laptop and use phones on the same Wi-Fi network as touch controllers.

# 

# \## Requirements

# 

# \- Node.js 18 or later

# \- A modern browser

# \- Laptop and phones connected to the same Wi-Fi network

# 

# \## Start the Game

# 

# 1\. Install Node.js.

# 2\. Open PowerShell in the project folder.

# 3\. Run:

# 

# &#x20;  ```bash

# &#x20;  node server.js
